# 방향과 팔레트

4단계가 한 아이디어의 변형 셋이 아니라 진짜 선택지를 내놓게 만드는 규칙들이다.

## 규칙 1. 셋 사이의 거리를 강제한다

세 방향은 아래 축 중 **최소 둘**에서 갈라야 한다.

| 축 | 양 끝 |
|---|---|
| 색 온도 | 차가운 중립 / 따뜻한 중립 / 채도 높은 액센트 주도 |
| 밀도 | 갤러리 여백 / 균형 / 콕핏 밀집 |
| 서체 계열 | 지오메트릭 산세리프 / 네오그로테스크 / 에디토리얼 세리프 / 모노 성향 |
| 명도 기조 | 라이트 우선 / 다크 우선 |

제시할 때 각 쌍이 어느 축에서 갈렸는지 밝힌다. 둘을 대지 못하면 껍데기만 셋인 한 방향을
들고 있는 것이고, 사용자의 선택은 아무 의미가 없다.

**브리프가 이미 정한 축에서는 가르지 않는다.** 제약이 접근성 우선의 임상 데이터라면
밀도는 고정이고, 갈림은 색 온도와 서체에서 나와야 한다.

## 규칙 2. 일곱 역할, 액센트 하나

여기서 팔레트는 예쁜 색 일곱 개가 아니라 역할 일곱 개다. 역할마다 대비 목표가 따로
붙는데, 그것이 규칙 3 을 판단이 아니라 기계적인 검사로 만든다.

| 역할 | 하는 일 | 대비 목표 |
|---|---|---|
| 베이스 | 페이지 배경 | 기준면이다 |
| 표면 | 카드, 패널, 떠 있는 영역 | 기준면이다 |
| 글자 | 본문 | 베이스 위와 표면 위 4.5:1 |
| 보조 글자 | 부가 라벨, 시각, 도움말 | 4.5:1. 이것도 본문이다 |
| 구분선 | 블록 사이의 장식적 구분 | 없음 |
| 컨트롤 경계 | 컨트롤의 경계를 유일하게 나타내는 것. 배경색 없는 입력 필드, 선만 있는 버튼 | 베이스 위와 표면 위 3:1. WCAG 1.4.11 |
| 액센트 | 시선을 끄는 유일한 것. 액션, 포커스, 단 하나의 강조 | 면으로 쓰면 3:1, 글자로 쓰는 자리에서는 4.5:1 |

**이 중 두 행은 다섯이 틀렸기 때문에 생겼다.** 앞 판본은 `경계` 와 `글자` 를 각각 하나만
두었는데, 독립된 검증 실행 둘이 같은 벽에 부딪혔다. 카드 사이의 구분선과 이메일 입력
필드의 테두리는 법적 최소값이 다른 별개의 역할이고, 보조 글자는 UI 컴포넌트에 속하는
3:1 로 조용히 낮춰지고 있었다. 나누는 것이 군더더기가 아니다. 통과하는 팔레트와 깨진
채로 출시되는 팔레트를 가르는 자리다.

**검사하기 전에 그 선이 어느 쪽인지부터 정한다.** 없애도 정돈만 나빠질 뿐이면 구분선이다.
없애면 컨트롤이 어디서 시작하는지 알 수 없게 되면 컨트롤 경계이고, 1.3:1 로는 안 된다.

제약은 이렇다.

- **액센트는 하나.** 의미색 쌍(성공/위험)은 최대 하나 더하되, 화면이 실제로 상태를
  보고할 때만 넣는다.
- **베이스는 중립.** 브리프가 명시적으로 채도를 요구하지 않으면 채도 80% 미만.
- **양쪽 모드.** 모든 역할에 라이트와 다크 값을 준다. 아니면 단일 모드가 의도임을
  브리프에 적는다.

## 규칙 3. 대비비는 계산하고 추정하지 않는다

목표는 **본문 4.5:1**, **큰 글자와 UI 컴포넌트 3:1** 이고 양쪽 모드에서 지킨다.

이 단계에서 기계가 확정할 수 있는 유일한 것이고, 동시에 AI 가 만든 팔레트가 정확히
실패하는 자리다. 색 견본으로 늘어놓으면 좋아 보이는데 본문에서 3.1:1 로 떨어지는
팔레트는 그대로 출시됐다가 다시 쓰인다.

돌려라. 눈으로 때려잡지 않는다.

```python
def _lin(c):
    c = c / 255
    return c / 12.92 if c <= 0.04045 else ((c + 0.055) / 1.055) ** 2.4

def luminance(hex_color):
    h = hex_color.lstrip("#")
    r, g, b = (int(h[i:i+2], 16) for i in (0, 2, 4))
    return 0.2126 * _lin(r) + 0.7152 * _lin(g) + 0.0722 * _lin(b)

def ratio(fg, bg):
    a, b = luminance(fg), luminance(bg)
    hi, lo = max(a, b), min(a, b)
    return (hi + 0.05) / (lo + 0.05)

BASE, SURFACE, ACCENT = "#fafafa", "#ffffff", "#1d68c4"

# 실제로 내보낼 쌍마다 한 줄씩. 목표값은 그 역할이 가진 것을 쓴다
checks = [
    ("글자 / 베이스",        "#1a1a1a", BASE,    4.5),
    ("글자 / 표면",          "#1a1a1a", SURFACE, 4.5),
    ("보조 글자 / 베이스",    "#595959", BASE,    4.5),
    ("보조 글자 / 표면",      "#595959", SURFACE, 4.5),
    ("컨트롤 경계 / 베이스",  "#767676", BASE,    3.0),
    ("컨트롤 경계 / 표면",    "#767676", SURFACE, 3.0),
    ("액센트 면 / 베이스",    ACCENT,    BASE,    3.0),
    ("액센트 글자 / 베이스",  ACCENT,    BASE,    4.5),
    ("액센트 위 라벨",        "#ffffff", ACCENT,  4.5),
]
for label, fg, bg, target in checks:
    r = ratio(fg, bg)
    print(f"{label:22s} {r:5.2f}:1  목표 {target}  {'PASS' if r >= target else 'FAIL'}")

# 구분선 역할에는 목표값이 없다. 없는 목표를 지어내지 않는다.
# 브리프를 쓰기 전에 다크 모드 값으로 한 번 더 돌린다.
```

**기준을 못 맞추면 색상이 아니라 명도를 바꾼다.** 색상은 방향이 고른 것이고 명도는
접근성이 정하는 것이다. 대비를 통과시키려고 색상을 갈아 끼우면 사용자가 고른 방향을
조용히 버리는 셈이 된다.

## 규칙 4. 팔레트를 거꾸로 검색해 검증한다

팔레트가 생기면 액센트를 Awwwards 에 도로 넣는다.

```
https://www.awwwards.com/websites/?tag=<미감-슬러그>&palette=%23<HEX>
```

결과는 신호로 읽는다.

| 결과 | 읽는 법 |
|---|---|
| 의도한 분위기와 맞는 사이트들 | 이 팔레트는 이 미감에 속한다. 둘을 레퍼런스로 인용한다 |
| 아무것도 없거나 몇 개뿐 | 드문 조합이다. 틀렸다는 뜻은 아니지만 브리프에 적는다 |
| 전혀 다른 분위기 | 팔레트가 방향과 싸우고 있다. 액센트를 다시 본다 |

**개수 행이 아니라 분위기 행에 무게를 둔다.** 2026-09-02 에 서로 무관한 액센트 셋이
`tag=minimal` 에 대해 모두 한 페이지를 채워 돌아왔다. 필터가 그만큼 헐거워서 「비어
있음」은 거의 발동하지 않는다. 실제로 쓸 수 있는 판정은 돌아온 사이트들이 그 방향처럼
느껴지는가 하나뿐이고, 그것은 사용자가 링크를 열어서 내리는 판단이다.

조회와 팔레트가 만나는 유일한 자리이고, Awwwards 에 색 필터가 있다는 사실 위에 서
있다. 판정은 다른 조회 결과와 마찬가지로 실마리이지 증명이 아니다.

## Coolors 로 내보내기

역할을 이 순서로 고정해서 잇는다. hex 는 `#` 없이 쓴다.

```
https://coolors.co/<베이스>-<표면>-<구분선>-<컨트롤경계>-<보조글자>-<액센트>-<글자>
```

앞 판본은 밝은 것부터 어두운 것 순으로 놓으라고 하면서 같은 자리에서 역할 순서를
지정했다. 다크 우선 팔레트에서는 두 지시가 서로 어긋나고, 검증 실행이 하나를 골라야
했다. 역할 순서가 이긴다. 순서가 고정되어야 두 브리프를 나란히 놓고 비교할 수 있다. 사용자가 열어서 손으로 돌려본다. 세션이 끝난 뒤에도 팔레트가
편집 가능하도록 URL 을 브리프에 넣는다.

## 타이포그래피

두 계열까지다. 제목과 본문. 하나여도 된다.

- Google Fonts 수록 여부를 확인하고 밝힌다. 유료 서체면 유료라고 말한다.
- 프로젝트가 창의적으로 들린다는 이유로 세리프를 집지 않는다. 세리프는 브리프가
  에디토리얼·럭셔리·헤리티지일 때, 또는 브랜드가 이미 쓰고 있을 때다.
- 지오메트릭 산세리프와 네오그로테스크는 조합이 아니다. 한 서체가 일관되게 로드되지
  못한 것처럼 읽힌다.
