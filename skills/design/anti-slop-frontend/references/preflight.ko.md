# 프리플라이트 체크 & 리디자인 프로토콜

`anti-slop-frontend` 스킬용 레퍼런스. 페이지를 "완료" 선언하기 전에 기계적 패스를 돌려라. 리디자인이면 감사를 먼저.

## 프리플라이트 체크 (기계적, "완료" 전)

**히어로**
- 초기 뷰포트에 맞음. 데스크톱에서 헤드라인 ≤ 2줄. 서브텍스트 ≤ 20단어 AND ≤ 4줄. CTA 스크롤 없이 보임.
- 폰트 스케일을 에셋 크기와 함께 계획. 기본 `text-4xl md:text-5xl lg:text-6xl`; `text-6xl md:text-7xl` 은 3–5단어 헤드라인만. 4줄 히어로 헤드라인은 폰트-크기 에러지 카피-길이 에러가 아니다.
- 상단 패딩 ≤ `pt-24` 데스크톱. 더 많으면 레이아웃 버그처럼 보임.
- 텍스트 요소 최대 4개: (eyebrow OR 브랜드 스트립 OR 없음) + 헤드라인 + 서브텍스트 + CTA(주 1개 + ≤ 부 1개). 히어로 금지: CTA 아래 태그라인, 신뢰 마이크로-스트립, 가격 티저, 피처 불릿, 아바타 행 — 모두 아래 섹션으로.
- "Used by / Trusted by" 로고 월은 히어로 아래로, 안에 넣지 마라.
- 히어로엔 실제 비주얼 필요. 텍스트 + 그라디언트 블롭은 플레이스홀더지 히어로 아님.

**내비게이션**
- 데스크톱(`lg` 1024px)에서 한 줄로 렌더. 안 맞으면: 라벨 압축, 부차 항목 제거, 햄버거로. 두 줄 내비 = 깨짐.
- 높이 ≤ 80px 데스크톱, 기본 64–72px.

**리듬 & 일관성**
- eyebrow 개수 ≤ ceil(섹션수 / 3). `uppercase tracking` 스몰캡스 라벨을 센다.
- image+text 지그재그 연속 ≤ 2행.
- 각 레이아웃 계열 최대 한 번; 8섹션 페이지에 ≥ 4개 계열.
- 페이지 전체에 액센트 컬러 하나(웜-그레이 사이트의 섹션 7에 블루 CTA 금지).
- 코너 반경 스케일 하나(all-sharp, all-soft 12–16px, all-pill) — 혼합은 문서화되고 준수되는 규칙 있을 때만.
- 페이지당 테마 하나 고정(다크 페이지에 라이트-웜-페이퍼 섹션 금지). 예외: 의도적 "스크롤 시 테마 전환" 장치, 페이지당 한 번.
- 페이지당 카피 레지스터 하나.

**접근성 (a11y)**
- 버튼 대비 WCAG AA(본문 4.5:1, 큰 텍스트 ≥ 18px 는 3:1). 금지: 흰 버튼 + 흰 글자, 테두리 없이 페이지 위 투명 버튼, 스크림/스트로크 없이 사진 위 고스트 버튼.
- 폼 대비: 입력, 플레이스홀더, 포커스 링, 헬퍼 텍스트, 에러 텍스트 모두 AA 통과.
- CTA 텍스트 데스크톱에서 한 줄(주 CTA ≤ 3단어, 이상적으로 1–2). 줄바꿈 CTA = 실패.
- 중복 의도 CTA 금지("Get in touch" + "Contact us" + "Let's talk" = 한 의도 → 한 라벨을 어디서나).
- 라벨 입력 위, 에러 텍스트 아래, 플레이스홀더-라벨 절대 금지.

**모션 & 성능**
- MOTION_INTENSITY 3 초과 모션은 `prefers-reduced-motion` 존중, 정적으로 붕괴.
- `transform` 과 `opacity` 만 애니메이트; `top`/`left`/`width`/`height` 절대 금지. `will-change` 는 아껴서.
- LCP < 2.5s(히어로 이미지 `priority`/프리로드), INP < 200ms, CLS < 0.1(이미지/폰트/임베드 공간 예약).
- 그레인/노이즈는 고정 `pointer-events-none` 유사 요소에만, 스크롤 컨테이너엔 절대 금지.
- z-index 는 체계적 레이어(내비, 모달, 오버레이, 그레인)에만; 스케일 문서화.

**카피 자가 감사**
- 보이는 모든 문자열(헤드라인, 서브헤드, eyebrow, 버튼 라벨, 본문, 캡션, alt, 푸터, 에러) 재독. 문법 깨진 것, 지시 대상 불명확, AI 환각 귀여운 말장난, 가짜로 정밀한 조작 숫자 재작성.

**이미지**
- 미니멀 사이트조차 실제 이미지 ≥ 2–3개(히어로 + 제품/라이프스타일 샷 + 보조 하나). 이미지-gen 툴 있으면 사용; 없으면 실제 사진 소스; 최후엔 라벨된 플레이스홀더 슬롯 + 사용자 통지. div 기반 가짜 스크린샷 절대 금지. 로고 월은 실제 SVG 로고(Simple Icons / devicon), 로고만(아래 카테고리 라벨 금지).

## 리디자인 프로토콜

작업이 기존 UI 개선일 때(그린필드 아님):

1. **먼저 감사, 맹목적 재스타일 금지.** 현재 UI를 읽고 실제 문제를 명시: 레이아웃, 간격, 위계, 대비, 타이포, 모션, a11y. 어디로 가야 하는지 Design Read 산출(보존 vs 전면개편).
2. **보존 vs 전면개편**은 브리프에서. 보존: 구조 유지, 간격/위계/대비/타입 수정, 다이얼 ≈ 기존 +1 모션. 전면개편: 다이얼 +2 variance/motion, density 유지.
3. **기존 브랜드 자산 존중** — 로고, 컬러, 타입, 사진은 출발 재료.
4. **그다음** SKILL.md 의 안티-디폴트 규율과 절대 불가를 적용하고, 배포 전 이 프리플라이트를 돌려라.
