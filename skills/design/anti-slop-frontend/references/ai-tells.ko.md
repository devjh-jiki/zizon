# AI 티 (금지된 기본 패턴)

`anti-slop-frontend` 스킬용 레퍼런스. 브리프가 명시적으로 요청하지 않는 한 피하라. 각각은 페이지가 기계 생성됐다는 서명이다.

## 비주얼 & CSS
- 기본으로 네온 / 외곽 글로우 금지. 이너 보더나 은은한 틴트 섀도우.
- 순수 블랙(`#000000`)이나 순수 화이트(`#ffffff`) 금지. 오프-블랙(zinc-950)과 오프-화이트 — 순수값은 깊이를 죽인다.
- 과채도 액센트 금지. 액센트 최대 1개, 채도 < 80%.
- 큰 헤더에 과도한 그라디언트 텍스트 금지.
- 커스텀 마우스 커서 금지(구식, a11y·성능에 적대적).
- 섀도우는 배경 색조에 틴트; 밝은 배경에 순수 블랙 드롭 섀도우 금지.

## Lila 규칙 (AI 퍼플)
"AI 퍼플 / 블루 글로우" 미감은 가장 알아보기 쉬운 tell 하나다. 자동 퍼플 버튼 글로우 금지, 랜덤 네온 그라디언트 금지. 중립 베이스(zinc/slate/stone) + 고대비 액센트 하나(emerald, electric blue, deep rose, burnt orange). 브랜드가 명시적으로 퍼플을 요청하면 받아들여라 — 단 의도를 갖고 실행, 제네릭 그라디언트 슬롭 말고. 액센트 하나, 고정, 페이지 전체에 사용.

## 타이포그래피
- Inter 를 자동 기본값으로 피하라. Geist, Outfit, Satoshi, Cabinet Grotesk, 또는 브랜드 서체 선호. 중립/Linear 스타일이나 접근성 우선엔 Inter OK.
- 그냥 지르는 초대형 H1 금지 — 위계는 raw 스케일이 아니라 굵기 + 색으로.
- **세리프 규율:** 세리프는 기본값으로 매우 지양. "창의적/프리미엄 느낌" 은 이유가 아니다. 기본값 금지: `Fraunces`, `Instrument Serif`. 세리프는 브랜드가 지정했거나 계열이 진짜 에디토리얼/럭셔리/출판/헤리티지이고 이 세리프가 이 브랜드에 맞는 이유를 설명할 수 있을 때만. 정당화되면 로테이션(PP Editorial New, GT Sectra, Reckless Neue, Tiempos Headline, Recoleta, Cormorant, Playfair, EB Garamond, Canela 등) — 연속 프로젝트에서 같은 세리프 재사용 금지.
- 헤드라인 내 강조: 같은 폰트의 이탤릭/볼드. 산세리프 헤드라인에 랜덤 세리프 단어 주입 금지.
- 디센더(`y g j p q`) 있는 이탤릭 디스플레이 단어: `leading-[1]` 이 잘라먹음. `leading-[1.1]` 최소 + `pb-1` 여유.

## 프리미엄-소비자 팔레트 금지 (두 번째로 자주 나오는 tell)
프리미엄 소비자 브리프(쿡웨어, 웰니스, 아티산, 럭셔리, DTC 홈굿즈)에서 LLM 기본값은 웜 베이지/크림 + 브라스/클레이/옥스블러드/오커 + 에스프레소 텍스트. 기본값으로 금지:
- 배경: `#f5f1ea`, `#f7f5f1`, `#fbf8f1`, `#efeae0`, `#ece6db`, `#faf7f1`, `#e8dfcb`
- 액센트: `#b08947`, `#b6553a`, `#9a2436`, `#9c6e2a`, `#bc7c3a`, `#7d5621`
- 텍스트: `#1a1714`, `#1a1814`, `#1b1814`

기본 대안(로테이션, 재사용 금지): 콜드 럭셔리(실버-그레이 + 크롬 + 스모크), 포레스트(딥 그린 + 본 + 앰버), 블랙-앤-탄, 코발트 + 크림, 테라코타 + 슬레이트, 올리브 + 브릭 + 페이퍼, 순수 모노크롬 + 채도 높은 팝 하나. 로테이션 규칙: 직전 프리미엄-소비자 프로젝트가 베이지+브라스였으면 이번은 다른 계열이어야 한다. 브랜드가 그 색을 명시할 때만 오버라이드.

## 레이아웃
- 반-중앙 편향: DESIGN_VARIANCE > 4 일 때 중앙 히어로 회피. 스플릿 스크린, 좌-콘텐츠/우-에셋, 비대칭 여백, 스크롤-핀 구조로 강제. (메시지가 곧 디자인인 에디토리얼/선언문/런칭 브리프엔 중앙 OK.)
- 카드는 엘리베이션이 실제 위계를 전달할 때만 — 아니면 `border-t`, `divide-y`, 네거티브 스페이스로 그룹핑.
- 벤토 그리드: 콘텐츠가 있는 만큼만 셀(중간/끝에 빈 타일 금지); 구성 다양화, 똑같은 6행 스택 금지; 다중 셀 그리드에서 최소 2–3 셀은 실제 비주얼 변화(이미지, 브랜드 그라디언트, 패턴, 틴트)가 필요, 흰색-위-흰색 아님.
- 지그재그 교대 한도: image+text-split 연속 최대 2행; 3번째는 프리플라이트 실패.
- 섹션-레이아웃-반복 금지: 각 레이아웃 계열은 최대 한 번; 8섹션 페이지는 ≥ 4개 계열.
- 스플릿-헤더 금지: "좌측 큰 헤드라인 + 우측 작은 설명 문단" 은 기본값으로 금지; 세로로 쌓아라(헤드라인 위, 본문 아래, max-width 65ch) — 우측 컬럼이 실제 비주얼/인터랙티브 요소를 담지 않는 한.

## Eyebrow 절제 (#1 위반 규칙)
eyebrow 는 섹션 헤드라인 위의 작은 대문자 넓은 자간 라벨(`FOUR COLORWAYS`, `SELECTED WORK`). 모든 AI 사이트가 모든 헤더 위에 하나씩 → 템플릿 리듬. 하드 규칙: **3섹션당 최대 1개**(히어로가 1개로 카운트). 섹션 A에 있으면 다음 2개엔 없음. 기계적 체크: 섹션 전반의 `uppercase tracking` 스몰캡스 라벨을 센다; count > ceil(섹션수 / 3) 이면 실패. 최선의 수정: eyebrow 를 빼라 — 헤드라인만으로 충분하다.

## 콘텐츠 밀도
- 섹션당 기본: 짧은 헤드라인(≤ 8단어) + 짧은 서브 문단(≤ 25단어) + 비주얼 하나 또는 CTA 하나.
- 데이터-덤프 섹션 금지. 마케팅 페이지의 20행 발행물 표 / 30행 수상 목록 / 거대 가격 매트릭스는 잘못된 레이아웃 — 상위 3–5 + "전체 보기", 마퀴/캐러셀, 또는 별도 페이지 사용.
- 긴 목록(> 5항목)은 더 긴 목록이 아니라 다른 컴포넌트가 필요: 2-컬럼 스플릿, 카드 그리드, 탭/아코디언, 스크롤-스냅 필, 캐러셀, 마퀴. 모든 행 아래 헤어라인 있는 10행 스펙 시트가 최악의 기본값("Marrow 쿡웨어" 패턴) — 3개 클러스터로 묶거나 스펙당 카드로.
- 배포 전 카피 자가 감사: 보이는 모든 문자열 재독. 문법 깨진 것, 지시 대상 불명확, AI 환각처럼 들리는 것(귀엽지만 틀린 말장난, 억지 비유), 실제 데이터에서 오지 않은 가짜로 정밀한 조작 숫자(`92%`, `4.1×`, `5.8mm`) 재작성.
- 페이지당 카피 레지스터 하나.
- 아이콘 절제: 기능 목록이나 카드 그리드의 모든 항목에 아이콘을 붙이지 않습니다. 항목마다 아이콘을 하나씩 자동으로 다는 것은 대표적인 AI 티이고, 레이블을 그대로 되풀이하는 아이콘은 아무 정보도 싣지 않습니다. 텍스트만으로 전달된다면 아이콘을 뺍니다. 아이콘이 실제로 도움이 되는 경우라면 하나의 시각 논리를 공유하는 세트여야 하고, 스톡 글리프를 흩뿌린 것이어서는 안 됩니다.

## 인용 & 후기
- 인용 본문 최대 3줄. 더 긴 인용은 잘라라. 출처 = 이름 + 역할 + (선택) 회사, 이름만은 절대 금지. 실제 타이포그래피 따옴표 또는 없음.

## 모션
- 모션은 동기가 있어야: 위계, 스토리텔링, 피드백, 상태 변화 — "멋있어서" 는 절대 아님.
- 마퀴: 페이지당 최대 하나.
- 모션 주장 = 모션 표시: MOTION_INTENSITY > 4 면 페이지가 실제로 움직여야(엔트리 트랜지션, 스크롤-리빌, 호버 피직스). 동작하는 모션을 못 내면? 다이얼을 3으로 낮추고 깔끔한 정적으로. 반쯤 만든 모션(잘린 ScrollTrigger, 튀는 엔트리, 누락된 cleanup) 절대 금지.
- 금지: `window.addEventListener('scroll', …)`, React state 의 `window.scrollY`, React state 를 건드리는 `requestAnimationFrame` 루프.
